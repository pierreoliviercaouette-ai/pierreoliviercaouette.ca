Suivi RDV Outlook Bookings → Meta Schedule
==========================================

SANS Power Automate Premium (cas actuel)
----------------------------------------
L’action « HTTP » de Power Automate exige une licence Premium.
Sans ça, Automate ne peut pas appeler Meta Conversions API.

Suivi possible sur le site (déjà branché) :
1) Formulaire /contact → événement Meta Lead (automatique)
2) Après réservation dans le calendrier Outlook, le visiteur clique
   « Oui, j’ai réservé » → /rendez-vous/merci → événement Meta Schedule

L’iframe Bookings est cross-origin : le site ne peut pas lire la confirmation
tout seul. Le clic explicite est le suivi Schedule sans Premium.
