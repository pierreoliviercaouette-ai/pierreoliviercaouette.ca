# Brief d’audit — lisibilité visuelle

## Objectif
Chaque formation doit être **facile et plaisante à lire** : ni mur de texte, ni fiche trop résumée.

## Focus principal : le rythme de lecture
1. **Paragraphes** : 2–4 phrases max. Couper les blocs > ~450 caractères.
2. **Sections** : 4–5. Titres concrets (verbe ou question), **sans** préfixe `1.` `2.`
3. **Densité** : chaque section = 2–3 paragraphes utiles. Pas 5 pavés ; pas 1 seule phrase vague.
4. **Une seule liste** de 3–4 puces max dans tout le module (hors takeaways).
5. **Takeaways** : 3–4 phrases **courtes** (une idée chacune).
6. **Exemple** : 4 étapes max, détails d’une à trois phrases. Timeline + exampleDiagram alignés (mêmes chiffres, labels courts).
7. **Diagramme conceptuel** : labels **courts** (≤ ~35 car.), hints ≤ ~40 car. Qualitatifs.
8. **Vocabulaire** : accessible ; jargon expliqué à la 1ʳᵉ occurrence, une fois.
9. **Pas de méta** « Selon l’AMF… » dans le corps.
10. Garder précision + `sources[]`. Chiffres d’exemple seulement dans workedExample / timeline / exampleDiagram / 1 quiz.

## Fichier
Réécrire **uniquement** `modules/<id>.js`.
