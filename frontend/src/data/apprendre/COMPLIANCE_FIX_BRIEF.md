# Brief — décisions conformité (corrections minimales)

## Mandat
Pour chaque point du rapport `docs/apprendre-conformite-rapport.md` visant **ton module** :

1. **Vérifier** (sources officielles si chiffre/règle).
2. Classer chaque point :
   - `CONFORME` — exact / déjà suffisamment nuancé → **ne rien changer**
   - `NON_NECESSAIRE` — ton, exhaustivité, sources « nice to have » → **ne rien changer**
   - `CORRECTION_REQUISE` — faux, trompeur, ou non conforme pour un contenu éducatif CSF → **corriger au minimum**
3. Ne corrige **que** `CORRECTION_REQUISE`. Pas de refactor, pas d’enrichissement « pour faire beau ».
4. Préférer 1–3 phrases reformulées plutôt qu’une réécriture.

## Seuil « 100 % nécessaire »
Corriger seulement si un lecteur raisonnable pourrait croire une **règle fausse** ou une **promesse / amalgame trompeur** (ex. REER = hors succession comme une assurance vie ; impôt sur le montant du gel entier ; chiffre réglementaire erroné).

Ne pas corriger : ton un peu directif, disclaimer déjà sur la page, sources iA « trop présentes », graphiques sans bandeau local, liens services.

## Sortie
Liste :
`- [point] → CONFORME|NON_NECESSAIRE|CORRECTION_REQUISE — 1 phrase. Si corrigé : quoi.`
