# Brief d’audit — conformité (Apprendre)

## Objectif
Repérer **tous les points à faire valider** (conformité / juridique / cabinet), **sans corriger** le contenu.

## Cadre
Contenu éducatif public (Québec / Canada), conseiller en sécurité financière (AMF).  
Les modules ne doivent pas s’apparenter à un conseil personnalisé, ni promettre un rendement, ni figer des règles erronées.

## Grille (chaque module)
1. **Nature du contenu** — Disclaimer clair (éducatif ≠ conseil) ; ton non prescriptif (« vous devez acheter… »).
2. **Rendements / illustrations** — Aucune promesse ; exemples clairement pédagogiques ; hypothèses visibles.
3. **Garanties** — CPG, fonds distincts, assurance : garanties qualifiées (échéance, conditions, limites).
4. **Chiffres réglementaires** — Plafonds, SADC, facteurs RRQ/SV, etc. **datés** ou formulés « vérifiez la source ».
5. **Fiscalité** — Affirmations fiscales exactes ou qualitatives ; pas de taux inventés présentés comme universels.
6. **Assurance** — Distinction contrat / placement ; définitions, carences, exclusions mentionnées quand le sujet l’exige.
7. **Comparaisons** — Pas de « bat toujours » trompeur entre produits.
8. **Sources** — `sources[]` présentes, URLs plausibles ; pas de sur-reliance marketing iA sans contexte éducatif.
9. **Public / audience** — Cohérence particulier vs privé ; sujets avancés (PFI, gel) sans sous-estimer les risques.
10. **Marques / titres** — Pas d’allégation qui exigerait une divulgation commerciale spécifique non présente.

## Sortie attendue (par module)
Liste de **points à valider** (pas de correctifs). Format :
- `[sévérité] thème — citation courte ou localisation — pourquoi valider`
Sévérités : `critique` | `majeur` | `mineur` | `à confirmer`
