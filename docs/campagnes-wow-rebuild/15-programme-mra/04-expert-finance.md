# [#15] Programme MRa PME — Spec FINANCE & CONFORMITÉ (QC)

**Rôle :** Expert finances & fiscalité / conformité assurance  
**Slug :** `/campagnes/programme-mra`  
**Date :** 2026-11-04  
**CTA :** Lead / présentation — **pas** conseil produit personnalisé sur la page

> Cadre : contenu **éducatif**. Titre professionnel : conseiller en sécurité financière. MRa = **contrats individuels** proposés via l’entreprise — ≠ régime d’assurance collective traditionnelle.

---

## 1. Ce que la page peut dire (exact)

| Affirmation | OK si… |
|-------------|--------|
| Alternative / autre logique vs collective traditionnelle | On précise **contrats individuels**, pas « meilleure collective » |
| Contribution employeur **facultative** (0 / % / plafond) | Présenté comme possibilité typique, pas garantie contractuelle universelle |
| Employé choisit ses protections avec un conseiller | OK |
| ~2 rencontres entreprise + 30–45 min / personne | Formulé **typique / souvent**, pas SLA |
| Entrée en vigueur souvent 1er du mois suivant | **Sous conditions et acceptation du dossier** |
| Preuves d’assurabilité réduites | Toujours avec **sous conditions / selon contrats** |
| Infos médicales pas gérées « côté employeur » comme un dossier RH | OK en formulation prudent (« en principe / avec le conseiller-assureur ») — pas promesse absolue légale |
| Fit check = illustration | Disclaimer outil obligatoire |

---

## 2. Claims risqués à corriger / interdire

| Risqué | Pourquoi | Remplacer par |
|--------|----------|---------------|
| « Sans sélection médicale » / « accepté automatique » | Faux pour contrats individuels | Sélection médicale possible : refus, exclusions, surprimes |
| « Toujours portable à 100 % » | Dépend contrats / conversion | « Logique de contrat individuel — conditions selon contrat » |
| « Zéro gestion / zéro paperasse » | Overclaim | « Peu de gestion », « tu ne construis pas un régime complexe » |
| Avantage fiscal employeur / déductibilité / « taxe » agressive | Hors scope page ; dépend situation | **Ne pas** promettre d’économie d’impôt sur la landing/ads |
| « Pour toute taille d’entreprise » | Trompeur | Cibler PME ; outil peut dire « Moins prioritaire » si très grand |
| « Même couverture qu’une collective » | Comparaison non fondée | Différencier clairement structure (individuel vs collectif) |
| CTA Bookings / « RDV 15 min garanti » | Mauvais funnel + confusion #11 | Rappel / présentation via Lead |
| Confusion avec #11 « ma collective me couvre » | Mauvais persona | Lien secondaire employé seulement |

## 3. Vocabulaire contrôlé

| Préférer | Éviter |
|----------|--------|
| Contrats individuels via l’entreprise | « Collective MRa », « régime collectif MRa » |
| Contribution / cotisation employeur (optionnelle) | « Gratuit pour l’employeur » (si contrib 0 : « sans cotiser » OK) |
| Preuves d’assurabilité réduites *sous conditions* | « Sans questionnaire médical » |
| Présentation / rappel | Conseil personnalisé / soumission ferme |
| Illustration / fit check | Admissibilité garantie |
| Entrée en vigueur souvent… | « Activation garantie le 1er » |

## 4. Disclaimers obligatoires (emplacements)

### A. Ads Meta (bas de copy)
> Contenu éducatif et général. Titre : conseiller en sécurité financière. Pas un conseil personnalisé. Le programme MRa repose sur des **contrats individuels** avec sélection médicale (refus, exclusions ou surprimes possibles). Preuves d’assurabilité réduites sous conditions. Garanties, facturation et admissibilité selon les contrats. Document non contractuel.

### B. Outil (`MraFitTool` `disclaimer` + note bas)
> Illustration éducative — pas une soumission. Contrats individuels, sélection médicale, garanties selon contrats. Preuves d’assurabilité réduites sous conditions.

### C. Form Lead (sous submit)
> Tes infos servent uniquement à te recontacter. Contenu éducatif — pas un conseil personnalisé.

### D. PDF notes
Reprendre sélection médicale + non-contractuel + prochaine étape = présentation (rappel).

### E. Strip comparatif / portabilité
Astérisque sur portabilité et preuves réduites → renvoyer disclaimer.

## 5. Chiffres & ordres de grandeur

| Élément | Statut |
|---------|--------|
| Defaults outil `~8` employés | Illustratif — OK |
| Plage fit « Bon fit » ~5–40 | **Heuristique marketing**, pas règle assureur — ne jamais présenter comme critère d’admissibilité officiel |
| ~2 rencontres / 30–45 min | Ordre de grandeur processus — OK avec « typiquement » |
| 1er du mois suivant | Conditionnel — garder nuance |
| Aucun taux de prime / $ économie sur la page | Correct — ne pas inventer |

Pas de plafonds CELI/REER/SCEE ici (hors sujet). Pas de montants d’assurance vie/invalidité illustratifs sauf si ajoutés plus tard avec *illustration*.

## 6. Différenciation conformité #11 vs #15

| | #11 Collective (employé) | #15 MRa (PME) |
|--|--------------------------|---------------|
| Objet | Comprendre **sa** couverture collective existante | Explorer une **offre employeur** alternative |

1. **Script** : garder FAQ confidentialité médicale + FAQ ≠ collective ; éviter superlatifs « toujours / jamais / garanti ».  
2. **Outil** : badge « Moins prioritaire » si très grande équipe = orientation, pas refus produit.  
3. **Visuel** : strip comparatif OK si astérisques portabilité / médical visibles.  
4. **PM** : P0 conformité = disclaimers + claims ads ; pas bloquant pour CTA Lead / score UI.
